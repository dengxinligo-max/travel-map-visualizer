# 风格选择与配色应用

## 选项

配色以 [palettes.json](../assets/palettes.json) 为准。编号和名称稳定；选择示例固定使用用户指定的“帕米尔路书 · 六种配色”完整对比图，保存在 `assets/style-preview.png`，不另生成抽象色卡替代。

| 编号 | 主题 | 适合的表达 |
|---|---|---|
| 01 | 冰川蓝 × 青柠 | 清爽明亮，突出水系与路线 |
| 02 | 青玉绿 × 珊瑚 | 温润自然，通用路书、城区漫游 |
| 03 | 午夜蓝 × 香槟金 | 深色、冷静，夜色海报与屏幕阅读 |
| 04 | 炭黑 × 落日橙 | 鲜明对比，自驾与户外主题 |
| 05 | 沙岩赭 × 孔雀蓝 | 暖色纸感，山地与人文旅行 |
| 06 | 雾紫灰 × 莓果红 | 柔和轻盈，旅行分享与设计感海报 |

展示 `assets/style-preview.png`（用安装后的绝对路径嵌入图片）或 `assets/style-preview.html`（仅展示同一张图，可离线预览），然后询问：“这次地图攻略想用哪种风格？可以回复 01–06、名称、自定义配色，或‘你来推荐’。”异步工具可列六个编号名称和“你来推荐”，自由文本输入承担自定义需求；不要分成多轮浅色/深色、色系、强调色问卷。

只在用户委托选色时推荐。无特别偏好可选 02；想突出山地暖色可选 05；明确需要深色可在 03/04 中按克制或醒目选择。推荐依据是设计判断，不是固定地域规则。用户已有明确选择时不再推荐或索要确认。用户仅要求多方案预览时直接给对比，选择可以在预览之后发生。

## 记录与应用

在 `trip.json` 保存：

```json
"style": {"id": "02-jade-coral", "name": "青玉绿 × 珊瑚", "selection": "explicit"}
```

`selection` 可为 `explicit`（用户指定）、`delegated`（用户让助手决定）、`inherited`（同一地图沿用）、`custom`。新行程不自行沿用上次选择，除非用户要求延用或明确设为长期偏好。不要因本轮选择修改跨会话记忆。

对于基础渲染器输出，在地图、地形、额外版式完成之后运行：

```sh
python3 scripts/apply_style.py /path/to/base-output --style 02 --selection explicit --out /path/to/final-output
```

该脚本接受 01–06 或完整主题 id，处理基础模板的 SVG 颜色、真实地形阴影与 HTML 外围颜色；保留原始路径与文字，并保存主题记录。`--selection` 填写实际选择来源，或继承输入中同 id 的选择记录；生成多方案时用 `preview`，不要将其记为用户已选。输入与输出必须是不同目录，且输出目录为空；已有配色结果不要再次套色，切换风格应从同一份原始渲染输出生成。脚本不复制地图大文件，输出行程中的地图路径会指回源数据；跨设备打包时另带数据并改为相对路径。之后从最终 HTML/SVG 导出 PNG，检查图例、标注、路线和正文对比。

颜色角色包含 `bg`（底色）、`ink/muted`（正文/次要文字）、`card/label`（信息卡/标签）、`accent`（主要路线）、`must/mustInk`（必去标记/文字）、`water/river`（水域/河名）、`road/minor`（主次道路）、`county`（区县名）、`relief`（真实地形色调）。自定义颜色在新输出中记录为 `style.tokens`，按这些角色应用；不要假称任意第三方 SVG 都能自动换色。多条路线保留可区分颜色与文字编号，不能一律压成同一色。

示例图只供比较配色，不作为新行程的地图、景点、路线或时效信息来源。正式地图仍须按用户区域下载真实数据，不将示例地区的源地图数据打包进 Skill。新增或调整配色时保持主题参数与示例一致；需要更新示例图时按用户要求替换。
